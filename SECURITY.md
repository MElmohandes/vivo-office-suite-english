# Security and private data

Do not open a public issue containing credentials, session cookies, account profiles, contact exports, personal files or precise device locations. Use GitHub private vulnerability reporting if enabled; otherwise submit a sanitized issue requesting a private reporting channel without disclosing exploit details or secrets.

This project modifies an installed application's archive. Preserve a known working backup, verify the documented hashes, and use only the supported original build. The builder does not require account credentials, request administrator access, install automatically or disable security controls. Only the manual installation step needs permission to replace a file under Program Files.

The hosted UI engine operates inside the app's existing service pages. It does not introduce a third-party translation API. Existing vivo network activity remains controlled by the vendor application and services.

Only the current recorded patch/build pair is supported. A future application or hosted-site change requires fresh review rather than bypassing hash or URL checks.
