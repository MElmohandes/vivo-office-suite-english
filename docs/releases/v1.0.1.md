# Chinese vivo Office Suite — English localization 1.0.1

For the same tested **vivo Office Suite 7.0.6 on Windows** build. Download the original software from **https://pc.vivo.com/**; newer versions offered there are not validated for this patch.

## Fixed

- Phone Mirroring and File Manager buttons silently doing nothing because internal action keys were translated. Six original action lookups are restored, and internal keys are protected from translation.
- Remaining Chinese labels in Calendar Events/To-dos forms: selected reminders, built-in calendar categories, the default To-do list and time-zone labels.
- Run-together year/month/day text in date picker fields.

Custom names, saved reminder values, category GUIDs, time-zone IDs and offsets are preserved.

## Easy installation

1. Download **app.asar.zip** from Assets and use **Extract All**.
2. Fully exit vivo Office Suite and its tray process.
3. Open `C:\Program Files (x86)\pcsuite\resources` (or your actual installation).
4. Back up the current `app.asar` under a new name. Keep older backups.
5. Copy in the extracted `app.asar`, keeping `app.asar.unpacked` and every other installed file in place.
6. Restart the app. To undo, exit it and restore your backup as `app.asar`.

No installer, Node.js or commands are required for the ready-made file. See the [beginner guide](https://github.com/MElmohandes/vivo-office-suite-english/blob/main/docs/INSTALLATION.md).
